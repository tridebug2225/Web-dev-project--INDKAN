INDKAN – Fresh Produce, Global Trade 🌿

A responsive website concept for a fruits, vegetables, and agricultural products import–export business. The project focuses on presenting products, connecting with international buyers, and making bulk trade enquiries easier.

📌 Project Overview

INDKAN aims to provide a clean, professional, and user-friendly online presence for agricultural trade. The website showcases product categories and allows potential business customers to explore products and submit bulk enquiry details through a form interface.

The design follows a fresh, nature-inspired visual identity using green tones and a responsive layout.

🎯 Project Objectives

- Create a professional website for an agricultural import–export business.
- Showcase fresh fruits, vegetables, and agricultural products.
- Provide an easy-to-use bulk enquiry form for business customers.
- Make the website responsive across desktop, tablet, and mobile screens.
- Practise front-end development using HTML, Bootstrap 5, and JavaScript.

✨ Features

- Responsive Navigation: Navigation links with a collapsible mobile menu.
- Hero Section: Brand introduction, promotional message, and call-to-action buttons.
- Product Categories: Sections for fresh fruits, fresh vegetables, agricultural products, and bulk supply.
- Bulk Inquiry Form: Form fields for customer details, destination country, product category, quantity, and additional requirements.
- Form Validation: Basic browser-side validation using HTML and JavaScript.
- Contact Section: A call-to-action for potential business enquiries.
- Footer: Brand information, quick links, and placeholders for social media links.
- Responsive Layout: Bootstrap grid and utility classes for different screen sizes.

🚀 Getting Started

Prerequisites

- A modern web browser.
- Visual Studio Code or another code editor.
- An internet connection to load Bootstrap from its CDN and display externally hosted images.

Installation and Setup

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that "index.html", "style.css", and "script.js" are in the same folder.
4. Open "index.html" in a browser, or run it using the Live Server extension in VS Code.
5. Resize the browser window to test the responsive layout.

Bootstrap 5 is loaded using a CDN, so a separate Bootstrap installation is not required for this version.

📝 Current Form Functionality

The bulk inquiry form currently demonstrates front-end validation. It checks required fields and displays a confirmation message when the entered information passes browser validation.

Important: The current form is a demonstration only. It does not send enquiries to a company email address or save information to a database. A backend or form-handling service would be needed for real submissions.
